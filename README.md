# Agentic Software Builder

An AI-powered application generator that converts natural-language requirements into complete software projects using specialized AI agents.

## Overview

The Agentic Software Builder automates key stages of software development, from requirement planning and architecture design to code generation, project validation, and automated repair.

## Features

* **Planner Agent:** Understands and organizes user requirements.
* **Architect Agent:** Proposes the project structure and technology stack.
* **Coder Agent:** Generates application files and supporting code.
* **Automated Validation:** Checks generated code and runs available tests.
* **Repair Loop:** Attempts to correct issues found during validation.
* **Multi-Stack Generation:** Supports configured project types such as Python CLI, Streamlit, FastAPI, and React/Vite.

## Tech Stack

* Python
* Groq API / LLM integration
* Agent-based workflow
* Automated testing and validation
* Git and GitHub

## Project Workflow

User Requirement → Planner → Architect → Coder → File Generation → Validation → Automatic Repair → Generated Application

## Example Project

A Python Streamlit Expense Tracker generated by the builder, featuring income and expense entries, category filtering, monthly summaries, charts, and CSV export.

## Getting Started

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install the required dependencies.
4. Configure your Groq API key in a local `.env` file.
5. Run `python main.py`.
6. Enter the application requirements when prompted.

## Setup

```bash
python -m venv .venv
```

On Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Create a local `.env` file containing your API key:

```text
GROQ_API_KEY=your_api_key_here
```

Never commit your `.env` file or real API keys.
